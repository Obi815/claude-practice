#Daily Status Report

Turn the activity log into a report with exactly these sections, in this order: 

## ✅ Done
- One bullet per finished item. Start with a verb ("Shipped", "Fixed").

## 🔄 In progress
- What's started but not finished, with progress if known.

## 🚧 Blockers
- Who or what is blocking, and what's needed to unblock it.
- If there are none, write "None."

## ⏭️ Next
- Top 3 priorities for tomorrow.

## Rules
- Max 12 bullets total. Short, plain language.
- End with a one-line **Summary:** sentence.
- Never invent work that isn't in the log.
